# Web Search - 网络搜索技能

## 核心功能

让 Trae AI 具备实时互联网搜索能力，解决知识截止日期限制。

1. **实时搜索** - 搜索最新新闻、技术文档、行业动态
2. **事实核查** - 验证信息和数据的准确性
3. **深度搜索** - 支持多轮搜索和结果聚合
4. **上下文引用** - 搜索结果自动关联对话上下文

## 使用方式

通过 Tavily MCP 服务器的 `tavily_search` 工具执行搜索。

AI 在以下场景自动触发搜索：
- 用户询问实时信息（"今天的新闻"、"最新版本"）
- 用户需要验证事实（"这是真的吗"、"确认一下"）
- 用户查找技术方案（"有没有更好的方式"）
- 知识截止日期之外的信息

## MCP 配置

```json
{
  "tavily": {
    "command": "npx",
    "args": ["-y", "tavily-mcp"],
    "env": {
      "TAVILY_API_KEY": "your-api-key"
    }
  }
}
```

已在 `C:\Users\38225\.trae-cn\mcp.json` 中配置。

## 最佳实践

1. **必须使用搜索** - 不确定的信息先搜索再回答
2. **引用来源** - 搜索到的信息标注出处
3. **控制搜索次数** - 同一主题不超过3次搜索
4. **结果去重** - 多个来源的信息交叉验证

## 搜索策略

| 场景 | 搜索深度 | 结果数 |
|------|---------|--------|
| 快速事实确认 | 浅度搜索 (topic: "general") | 3 |
| 技术问题解决 | 深度搜索 (topic: "general") | 5 |
| 综合性报告 | 多轮聚合搜索 | 5-10 |
| 新闻快讯 | 浅度搜索 (days: 1) | 3 |
