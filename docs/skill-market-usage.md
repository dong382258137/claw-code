# 技能市场使用说明

版本：2026.11.10（对应提交后的 `claw` / `claw-plus`）

这份说明只描述当前实际行为。所有路径以 Windows 默认配置家目录 `%USERPROFILE%\.claw` 为例；如果设置了 `CLAW_CONFIG_HOME` 或 `CODEX_HOME`，把 `~/.claw` 换成对应目录。

## 1. 打开

- 终端执行 `claw serve`：默认端口 4317，自动打开浏览器并带上一次性 token。
- 也可以 `claw serve --port 4317 --cwd <工作区> --no-open`，再手动访问启动日志里的地址。
- 只监听 `127.0.0.1`；关掉终端，服务即停止。
- 页面左侧栏进入「技能市场」，有三个页签：**本地技能**、**已安装**、**来源市场**。

## 2. 看

- **本地技能**：列出当前发现的全部技能，来源标为「项目 / 用户配置 / 用户目录 / 内置」。
  - 状态分三种：生效中、被遮蔽（有更高优先级的同名技能）、已禁用。
  - 搜索框按名称和描述过滤；点技能名进入详情，可看 `SKILL.md` 全文预览。
- **已安装**：只列「可卸载」的技能，即副本位于 `~/.claw/skills/` 下的技能。市场安装和命令行 `/skills install` 安装的都在这里。
- **来源市场**：管理索引来源，并在选中来源后列出可安装条目。
- 页面顶部统计：`x / y 生效 · n 已禁用 · m 可卸载`。

## 3. 装

### 3.1 从 WebUI 安装

1. 「来源市场」页添加来源，二选一：
   - 本地目录或 `marketplace.json` 的路径；
   - git 仓库地址（可填写仓库内子目录）。
2. 点选来源，下方出现该来源的索引；点「安装」。
3. 已安装的条目会显示当前版本，按钮变为「升级安装」，点击后需确认覆盖。
4. 安装结果：
   - 技能目录：`~/.claw/skills/<name>/`
   - 注册表：`~/.claw/skill-market/installed.json`
   - 目标已存在且没有选择升级：返回 409，不覆盖。
   - 索引版本在安装前发生变化：返回 409「索引版本已变化，请刷新后重试」。
   - 安装的副本被项目里的同名技能遮蔽时，页面提示「已被同名技能遮蔽」，模型实际调用到的不是这份副本。

### 3.2 git 来源的行为

- 新增来源和手动「刷新」时 clone 到 `~/.claw/skill-market/mirrors/<来源 id>`。
- 列表、索引、安装都只读本地镜像，安装不会临时联网。
- clone 使用 `--depth 1`，硬超时 30 秒；失败分类为「未找到 git」「拉取失败」「超时」，并保留具体 git 报错。
- 来源卡片会显示最近一次 clone 的短 commit。
- 删除来源会同时删除对应镜像，但不会卸载已安装的技能。

### 3.3 从命令行安装

- 交互式会话内：`/skills install <path>`、`/skills list`
- 非交互：`claw skills install <path>`、`claw skills list`（JSON 输出用 `--output-format json`）
- 与 WebUI 共用同一条原子安装流水线（暂存 → 校验 → rename → 写清单，失败回滚）。
- 实际差异：命令行安装**不写** `installed.json`。因此「已安装」页仍能看到它、也能卸载，但没有版本和来源元数据，卡片标注「命令行安装 · 无市场元数据」，也不会出现「升级安装」。

## 4. 启停

- 「本地技能」列表每项有启用/禁用开关；详情页也有同一开关。
- 禁用只改状态，不移动也不删除目录：
  - 状态文件：`~/.claw/skill-market/state.json`（只记录被禁用的名字集合）
  - 禁用后该技能不出现在 `/skills list`、系统提示的技能目录里，`Skill` 工具也搜不到。
- 启停是用户级全局状态，不区分工作区。
- 项目技能和内置技能不能卸载，但可以禁用。

## 5. 卸

- 入口：「已安装」→ 点技能 → 详情页「卸载」。
- 判定规则：副本是否位于 `~/.claw/skills/` 内，而不是看注册表。所以市场装的和命令行装的都能卸。
- 流程：目录先 rename 到 `~/.claw/skill-market/trash/`，注册表写成功后才真正删除；中途失败会回滚。
- 项目目录里的同名技能、内置技能没有卸载按钮，只能禁用。
- 删除来源不会卸载技能，两者相互独立。

## 6. 失败与降级（界面上能看到什么）

- **失败可见**：来源卡片显示状态标签、具体失败原因，以及「上次成功：<时间>」或「从未成功」。
  - 刷新失败时接口返回 502（拉取失败）/ 504（超时），页面顶部同时显示错误文案。
  - 失败刷新不会覆盖「上次成功」时间。
- **索引不可用时的降级**：索引读取成功后会写快照到 `~/.claw/skill-market/index-cache/<来源 id>.json`。
  - 来源不可读时，页面显示快照内容，并标注「索引当前不可用 …（最后更新于 …）」。
  - 刷新失败但本地镜像仍可读（git 来源）：标注「来源刷新失败 … 以下内容来自本地镜像」，仍可安装。
  - 索引完全不可读：标注「只能查看，无法安装」，安装按钮禁用。
  - 连缓存也没有：显示「索引不可用，也没有可用的缓存内容」，不会白屏，也不会一直转圈。

## 7. 数据位置

| 路径 | 内容 |
| --- | --- |
| `~/.claw/skills/<name>/` | 技能安装根（发现根）；卸载只删这里的副本 |
| `~/.claw/skill-market/installed.json` | 市场安装清单（版本、来源、commit） |
| `~/.claw/skill-market/sources.json` | 来源记录（状态、失败原因、上次成功时间、git commit） |
| `~/.claw/skill-market/state.json` | 启停状态（只记 disabled 集合） |
| `~/.claw/skill-market/mirrors/<id>/` | git 来源本地镜像 |
| `~/.claw/skill-market/index-cache/<id>.json` | 索引快照（降级用） |
| `~/.claw/skill-market/staging/`、`trash/` | 安装/卸载暂存，正常结束后为空 |

## 8. 已知限制

1. 来源只支持本地目录和 git 仓库；没有远程托管索引服务。
2. 不做签名、发布者身份校验；安装前只能靠索引内容和全文预览自行判断。
3. 不做自动更新、定时检查；升级必须手动点「刷新」和「升级安装」。
4. git 只做默认分支的浅克隆（`--depth 1`），不支持指定分支、tag 或历史版本。
5. 命令行安装不写 `installed.json`：WebUI 能看见、能卸载，但没有版本/来源信息，也不会提示可升级。
6. 没有批量刷新来源，也没有按标签筛选；搜索只匹配名称和描述。
7. 卸载不可恢复；`trash/` 只用于写入清单失败时的回滚，没有回收站界面。
8. 同名技能遮蔽沿用既有发现优先级，市场不参与冲突解决，只在安装后提示。
9. 启停是用户级全局状态，不是按项目/工作区隔离。
10. 只服务本机单用户：服务只绑定 `127.0.0.1`，没有多用户权限模型。
